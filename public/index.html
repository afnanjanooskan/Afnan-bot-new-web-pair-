How to Connect
📲
Pairing Code (Recommended)
Enter your phone number → get a 8-digit code → enter it in WhatsApp under Linked Devices → Link with phone number
📷
QR Code
Switch to QR tab → click Connect → scan the QR code with WhatsApp → Linked Devices → Link a Device
👑
Auto Owner
The first number to pair this bot becomes the owner. Owner commands (.broadcast, .sudo, .update, etc.) will only work for the owner.
📱
Multiple Devices
Add multiple sessions with different names. Each device logs in independently. Use the logout button to remove a device without deleting data.
